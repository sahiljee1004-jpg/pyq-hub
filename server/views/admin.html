Firestore-Managed Admin Access Control

In compliance with the VidyarthiAstra security architecture, admin privileges cannot be granted or revoked via application forms, bootstrap scripts, or client tokens. The sole authoritative source is the user's document in Cloud Firestore.

✓ Granting Administrator Access:
  1. Locate user's Firebase UID in Firebase Authentication.
  2. Open Firebase Console → Firestore Database.
  3. Open collection users → document {uid}.
  4. Set field: role = "admin" (type: string).
  5. Save. Access is granted immediately on next request.
✗ Revoking Administrator Access:
  1. Open user document at users/{uid} in Firestore.
  2. Change field role to "user" or delete field.
  3. Save. Privilege is revoked instantly on next request.
  4. Stale browser tokens cannot bypass this server check.
